Model Context Protocol (MCP) Server

Dokumentation und Anleitung zur Anbindung von KI-Assistenten.

Das Model Context Protocol (MCP) ist ein offener Standard, der es KI-Modellen (wie Anthropic Claude, Cursor, ChatGPT etc.) ermöglicht, sicher auf lokale und entfernte Datenquellen und Tools zuzugreifen. Das Abstimmungsstudio verfügt über einen integrierten MCP-Server, der Echtzeitdaten, historische Resultate, Demografie-Statistiken, Wählerwanderungs-Matrizen und Korrelationsanalysen direkt für Ihren KI-Assistenten bereitstellt.

Verfügbare Tools

Tool-Name Beschreibung Parameter
get_current_votes Holt alle Abstimmungsvorlagen des neuesten Abstimmungstags. region (optional)
get_vote_results Liefert die ausgezählten und hochgerechneten Resultate einer Vorlage sowie Konfidenzintervalle. vorlage_id (erforderlich)
perform_correlation_analysis Berechnet Pearson-Korrelationen zwischen Ja-Stimmen/Beteiligung und Gemeinde-Demografiewerten. vorlage_id, selected_metric
get_commune_statistics Liefert demografische/sozioökonomische Werte (z.B. Bevölkerungszahl, Alters buckets, Sektoren) für Gemeinden. vorlage_id, columns, geo_id
get_commune_results_for_vote Holt die Beteiligung, Ja-Stimmen-Prozent und Stimmberechtigte einzelner oder aller Gemeinden für eine Vorlage. vorlage_id, geo_id
perform_waehlerwanderung Berechnet die Transition-Matrix (Wählerwanderung) aus einer früheren Wahl oder Abstimmung. vorlage_id, source_type, source_id, wahlen_scope
get_voter_transition_options Liefert die Liste aller für eine Vorlage nutzbaren Quell-Wahlen/Abstimmungen. vorlage_id

Integrations-Anleitung

Verbindung über SSE / HTTP (Entfernte Verbindung)

Der Agent verbindet sich über das Netzwerk (Internet oder Intranet) mit dem MCP-Server. Der Zugriff wird über einen API-Key abgesichert.

Konfiguration im Client (z.B. Claude Desktop):

{
  "mcpServers": {
    "abstimmungsstudio-remote": {
      "url": "https://mcp.abst.d-o.li/sse?api_key=DEIN_GEHEIMER_API_KEY"
    }
  }
}

Beispiel: Python Client Script

Anbindung an den entfernten SSE-Server mittels des offiziellen Python MCP SDKs: 

import asyncio
from mcp import ClientSession
from mcp.client.sse import sse_client

async def fetch_results():
    url = "https://mcp.abst.d-o.li/sse"
    headers = {"Authorization": "Bearer DEIN_GEHEIMER_API_KEY"}
    
    async with sse_client(url, headers=headers) as streams:
        async with ClientSession(streams[0], streams[1]) as session:
            await session.initialize()
            
            # Führe Wählerwanderung aus
            res = await session.call_tool("perform_waehlerwanderung", {
                "vorlage_id": 6870,
                "source_type": "election",
                "wahlen_scope": "lager"
            })
            print(res.content)

asyncio.run(fetch_results())
